#
# Section 22.1 also asks for the Giac cross-check on this row. That cannot run on the host, since
# Giac is not linked here, so the cross-check is device evidence and this file carries the half a
# host can hold: the rule that fired, the answer, and that every displayed transformation carries a
# passing verification.
#
# The engine does not tidy its answer, so 2 * 1 and x^1 appear in what it returns. The comparison
# canonicalises both sides, which is why a case can name the tidy form.

# An expression that divides by zero has no value, so there is nothing to differentiate. The three
# cases where the zero is written out live in invalid.txt. This one is undefined only after the
# denominator folds, so it is the only one that reaches the guard's canonicalize-and-recheck branch
# rather than its raw-tree branch, and without it that branch is untested.
case derivative.adversarial.denominator-only-zero-once-folded
  family derivative
  input x/(2-2)
  variable x
  expect unsupported form
  detail the expression divides by zero, which has no value to differentiate

# The other side of the guard. A denominator that folds to one is not a division by zero, and the
# refusal must not reach it.
case derivative.adversarial.denominator-that-folds-to-one
  family derivative
  input x/(2-1)
  variable x
  expect differentiated
  result 1

# The third corner, where the zero is symbolic rather than written out. canonicalize still does not
# gather like terms, so this one is settled by the condition the reciprocal raises rather than by the
# divisor fold: a - a can never be non-zero, so the condition cannot be met and there is nothing to
# differentiate. It reached the guard's other branch, which is why the case is here and not beside
# the two above.
case derivative.adversarial.symbolic-denominator-that-cancels
  family derivative
  input x/(a-a)
  variable x
  expect unsupported form
  detail the expression is undefined here, so there is nothing to differentiate
